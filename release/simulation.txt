PinMAME Simulation
------------------

PinMAME features a rudimentary way to 'play' a pinball machine without
having to use a full simulator (e.g. Visual Pinball). So one can trigger
certain gameplay situations (like making a full loop or ramp shot) via
simulation keys, or trigger specific switches via switch keys (see below).
Note that not all games feature the same level of support (see
https://github.com/vpinball/pinmame/tree/master/src/wpc/sims
for a folder hierarchy with all games that support full or at least
preliminary simulation support).
This feature can aid in debugging homebrew games, or reverse engineering
existing games (or when trying to improve PinMAME emulation itself).

The ball simulator can handle up to 7 balls in the machine. The simulator
ensures that the correct switches are activated, depending on where the
balls are.

You can change the location of the simulated balls with the keyboard.
Example: Pressing LCTRL+R will send the ball up the left ramp activating
the switches associated with a complete ramp shot.
The simulator will also keep track on diverters, gates and other solenoids
to ensure that the ball ends up in the correct place.

Normally the simulator prevents impossible combinations (e.g. a ball in
the trough making a left ramp shot or a "dirty pool" in TAF). This can be
overridden by pressing the "Ignore Ball Location" button (Alt).

The general simulation keys are:

Up      Move cursor to Previous ball in the simulator
Down    Move cursor to Next ball in the simulator
Alt     Ignore ball location in simulator
Del     Toggle between simulator keys and switch keys.
Space   Shoot ball. If the game uses a manual shooter a bar will
        indicate the strength.

General simulator settings in the DIP switch menu:

Balls   Select 0 to 7 balls. Note that most games will be confused with
        the wrong number of balls (especially if too many).
Spinner Set the time a spinner "spins" after a hit (not used in existing
        simulators yet)

Keys for all simulators:
'+' means that the key must be pressed with Left or Right CTRL key.
'Left Ctrl' + 'R' means Left Ramp, 'Right Ctrl' + 'S' means Right Spiral)

Twilight Zone(TZ)
-----------------
DIP settings:
Third Magnet  - Activate third magnet switch and trap balls on magnet
Clock Passage - Activate clock passage opto
Big Kick      - Activate big kick opto (not implemented)

I don't know which ROM versions utilise which switches.

Known Bugs:
1. The balls doesn't always stop on the magnets. Probably some bad timing
   in the simulator.
2. The simulated clock got a digital display :-)

Dr. Dude (DD)
-------------
DD is orginally a System 11 game but a few of them were built using
WPC hardware. This means that the game uses the coin door switches
in a different way and that the checksum can not be disabled (game will
not start if trying).

Dr. Who (DW)
------------
DW is different from the other WPC games in that it has more power on
tests. Examples are that DW performs a very detailed testing of the WPC chip
and also uses a switch (82) to detect the playfield glass (due to its elevator).
Use the manual switch keys ('I' + 'S') to activate/deactivate the
playfield glass switch.

Cirqus Voltaire (CV)
--------------------
On startup, CV will test the ringmaster and it will not go into attract mode
if the test fails. One way to bypass it, is to disable the ringmaster
(adjustment A2 30).

Io Moon (iomoon)
----------------
Sleic's 1996 machine.  Three balls.  The simulator keys are:

  +-    Left/Right Shooter (the manual's Expulsor 1/2, i.e. the slingshots)
  +R    Ramp 1 / Ramp 2
  +H    Hole 1 / Hole 2 (Tragabolas 1/2)
  +B    Bull Eye 1 / Bull Eye 2 (Diana 1/2)
  WEDFG Bumpers 1-5
  J     Jupiter entrance
  I     Inner Bank (Fondo Bancada)
  O     Lane 10, the orbit shot
  K     Lane 11 (Autodrop)
  ZXCVN Drop targets Bank A-E
  YUAS  Lanes 1-4
  MLDot Lanes 5-7   (M, L, comma)
  ./    Lanes 8-9   (period, slash)
  Q     Drain
  Space Plunge the served ball (the cabinet has a manual shooter rod)
  Down  Follow the next ball -- press it once after each drain, or the shot keys
        go on being refused because the cursor still points at the drained ball

Del switches between these keys and the per-contact matrix test keys, which is
how the service menu's CONTACTOS test is driven; the matrix keys are listed in
sleic.c.  Those keys assign the whole matrix, so a Del round-trip also clears the
drop targets.

The drop targets otherwise only rise on ball start, as on the real machine: the
bank reset coil is on the driver expansion board and the firmware never resets it
mid-ball, so a mode that needs the bank cannot be completed if targets were
already down.

Hole 2 and Jupiter's two ball locks free the ball themselves after five seconds.
Hole 2 has no kicker at all -- the manual's coil list names one for Tragabolas 1
only -- and Jupiter's release coil is not seen firing in ordinary play, which
matches manual 3.3.7: without every ORBITS lamp lit Jupiter holds no ball.  So a
ball passing straight through either of them is the ordinary case, not a fault.
Hole 1 is different: it has a real coil and waits for it.
